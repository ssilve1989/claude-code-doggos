# Doggo: a golden retriever buddy mod for Claude Code

## Goal

A Claude Code mod that draws a pixel-art golden retriever that reacts to the
session, can be petted and fed, and remembers you across sessions. For fun,
in the terminal CLI (Ghostty, truecolor).

## Decisions

- **Art**: code-drawn pixel sprites (`art/build.py`, Pillow) generate
  `hooks/sprites.ts`. No runtime PNG decoding — hooks modules cannot import
  Node built-ins. Importing user-supplied PNG art is out of scope for now.
- **Rendering**: one `Raster` per drawing, two pixels per cell via `▀`/`▄`
  half-blocks; transparent pixels use the terminal default colour.
  Animation repaints with `$.ui.blit` on a `$.clock.every` timer
  (200 ms; 1 s while asleep; no timer when display is `off`).
- **Sizes**: full sprites (~48×37 px → 48 cols × 19 rows) in the pane;
  a mini sprite set (~16×12 px → 6 rows) in the band, with a speech bubble.
- **Display**: `band` (default) | `pane` | `off`, from `userConfig.display`,
  switchable with `/doggo band|pane|off`, persisted in `$.store`.

## Layout

```
.claude-plugin/plugin.json   name "doggo", userConfig (display, name)
hooks/hooks.json
hooks/register.tsx           wiring only: events → mood, commands, render, timer
hooks/mood.ts                pure state machine, no `$`
hooks/raster.ts              pure: frame → Raster cells
hooks/sprites.ts             GENERATED by art/build.py
art/build.py                 draws sprites, writes sprites.ts + preview.png
tests/*.test.ts              claude plugin test
```

## Moods

Pose shown = active reaction (expires after ~3 s) else base
(`idle` | `working` | `asleep`).

| Event | Pose | Bubble |
|---|---|---|
| `prompt.submit` | excited (reaction) | "ooh, a job!" |
| `turn.start` | base → working | — |
| `tool.call` Read/Grep/Glob | sniff | "sniffing <file>…" |
| `tool.call` Edit/Write | dig | "burying a change in <file>" |
| `tool.call` Bash | walk | "fetching `<cmd>`…" |
| `tool.call` Agent | walk | "calling the pack…" |
| tool result `isError` | worried (reaction) | "uh oh…" |
| `tool.check` → `ask` | tilt | "can we?" |
| `turn.complete` | happy (reaction), base → idle | "done! good boy?" |
| 10 min no activity | base → asleep | "zzz" |
| any event while asleep | wake, then handle | "huh? oh!" |

## Commands

One command, `/doggo <sub>` (`immediate: true`); mod command names cannot
contain `:`.

| Sub | Effect |
|---|---|
| (none) | toggle pane |
| `pet` | happy, +1 bond (max 5 per session) |
| `treat` | excited "nom!", +2 bond; 4th treat per session refused |
| `band` / `pane` / `off` | switch display (persisted) |
| `name <name>` | rename (default Biscuit) |

Commands print nothing when the dog is visible; with display `off` they
reply with a text line.

## Memory (`$.store`)

One key per value: `name`, `bond`, `treats`, `pets`, `sessions`, `fetched`,
`firstMet`, `lastSeen`, `display`. Increments re-read before writing.
`fetched` is flushed at most every 30 s and at `session.end`. Malformed values
fall back to defaults.

Bond levels: stranger 0–9, friend 10–49, best friend 50–199, soulmate 200+.
+1 per session. Session-start greeting depends on first meeting, same day,
or 3+ days away.

The pane shows sprite, name + bond level, stats, and `[p] pet` `[t] treat`.

## Robustness

- Observing hooks always pass the event through and carry `.catch` handlers
  that do so.
- Desktop (no `Raster`): a one-line text fallback.
- Narrow band: drop bubble; < 16 cols: text only. Pane < 48 cols: mini sprite.

## Testing

- `mood.ts`: transitions, reaction expiry, sleep/wake, pet cap, treat
  refusal, bond levels.
- `raster.ts`: half-block packing, transparency, encoded length.
- Integration via `claude plugin test`: commands update store, tool calls
  change the bubble, terminal draws `Raster` / desktop draws `Text`.
- `art/build.py`: asserts frame sizes and palette indices; writes preview.

## Out of scope

User PNG import, sound, multiple dogs, achievements.
